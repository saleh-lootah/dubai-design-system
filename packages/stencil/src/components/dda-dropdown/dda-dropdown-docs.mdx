# Dropdown

The `dda-dropdown` component renders a button with a three-dots icon that opens a list of options.
Use `icon_mode` for a compact icon-only menu, or show the selected option next to the icon.
Every time the user picks an option, the component updates its `selected` property and fires
`optionSelect` with `detail.value`, the option. It also fires when the user picks the option that
is already selected, so you can use the dropdown as an action menu.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-dropdown
  button_id="sort-requests"
  label="Sort requests"
  type="bg-white"
  size="medium"
  options='["Newest first","Oldest first","Status"]'
></dda-dropdown>

<script>
  document
    .querySelector('dda-dropdown')
    .addEventListener('optionSelect', event => console.log('Sort order:', event.detail.value));
</script>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-dropdown.js';

const dropdown = document.querySelector('dda-dropdown');
dropdown.options = JSON.stringify(['Newest first', 'Oldest first', 'Status']);
dropdown.addEventListener('optionSelect', event => {
  console.log('Sort order:', event.detail.value);
});
```

### React

```jsx
import { DdaDropdown } from '@dubai-design-system/components-react';

export function SortRequests({ onSort }) {
  return (
    <DdaDropdown
      button_id="sort-requests"
      label="Sort requests"
      type="bg-white"
      size="medium"
      options={JSON.stringify(['Newest first', 'Oldest first', 'Status'])}
      onOptionSelect={event => onSort(event.detail.value)}
    />
  );
}
```

### Vue

```html
<script setup>
import { DdaDropdown } from '@dubai-design-system/components-vue';

const options = JSON.stringify(['Newest first', 'Oldest first', 'Status']);
</script>

<template>
  <DdaDropdown
    button_id="sort-requests"
    label="Sort requests"
    type="bg-white"
    size="medium"
    :options="options"
    @optionSelect="event => console.log('Sort order:', event.detail.value)"
  />
</template>
```

## Icon-only menu

Set `icon_mode` to show only the three-dots icon, and `type="bg-transparent"` to remove the field
border and background. The button then has no visible text, so set `aria_label`. If `aria_label` and
`label` are not set, the button is named by `toggle_button_label` (default `Show options`).

```html
<dda-dropdown
  button_id="request-actions"
  aria_label="Request actions"
  icon_mode
  type="bg-transparent"
  options='["View details","Download receipt","Cancel request"]'
></dda-dropdown>
```
