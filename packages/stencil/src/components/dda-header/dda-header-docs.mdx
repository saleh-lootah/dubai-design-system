# Header

The `dda-header` component renders the site header: two logos, the main navigation with mega
menus, a side menu, search, an accessibility panel (contrast, screen reader, text size), a
language button and a Login link. Pass the menus as JSON strings and listen to the events to
react to the user's choices.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-header
  first-logo-src="/img/government-of-dubai.svg"
  first-logo-white-src="/img/government-of-dubai-white.svg"
  first-logo-alt="Government of Dubai"
  second-logo-src="/img/entity-logo.svg"
  second-logo-white-src="/img/entity-logo-white.svg"
  second-logo-alt="Dubai Digital Authority"
  login-link="/login"
  language_text="العربية"
  search_action="/search"
  quick-links='[{"label":"Home","href":"/"},{"label":"Services","menuLabel":"Services","href":"#","subMenu":[{"title":"Renew a trade licence","description":"Renew your licence online","icon":"badge","href":"/services/licence"}]}]'
  side-menu-items='[{"label":"Home","href":"/"},{"label":"Services","href":"#","subMenu":[{"headerLabel":"Services","label":"Business","href":"/services/business"}]},{"label":"Contact Us","href":"/contact"}]'
></dda-header>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-header.js';

const header = document.querySelector('dda-header');
header.quickLinks = JSON.stringify([
  { label: 'Home', href: '/' },
  { label: 'About', href: '/about' },
]);
header.sideMenuItems = JSON.stringify([
  { label: 'Home', href: '/' },
  { label: 'Services', href: '#', subMenu: [{ headerLabel: 'Services', label: 'Business', href: '/services/business' }] },
]);

header.addEventListener('languageSwitch', () => console.log('switch language'));
header.addEventListener('lgTextSize', () => console.log('larger text'));
header.addEventListener('searchSubmit', event => console.log('search', event.detail.query));
```

```html
<dda-header
  first-logo-src="/img/government-of-dubai.svg"
  first-logo-alt="Government of Dubai"

  second-logo-alt="Dubai Digital Authority"

  [sideMenuItems]="sideMenuItemsJson"
  (languageSwitch)="switchLanguage()"
  (searchSubmit)="search($event.detail.query)"
></dda-header>
```

In the component class, set `quickLinksJson` and `sideMenuItemsJson` to `JSON.stringify(...)` of
the menu arrays.

## Menus

`quick-links` builds the main navigation. An item without `subMenu` is a plain link. An item with
a `subMenu` opens a mega menu titled `menuLabel`; each entry shows a Material Symbols `icon`, a
`title` and a `description`.

`side-menu-items` builds the side menu that the hamburger button opens. A `subMenu` opens a nested
list; `headerLabel` of its first item is the list title. Sub-menus can nest to any depth.

## Accessibility panel

The panel has no built-in effect on the page. It emits events, and your code applies the change:

<table>
  <thead><tr><th>Control</th><th>Event</th></tr></thead>
  <tbody>
    <tr><td>Normal, Colours Blind, Red Weakness, Green Weakness</td><td><code>normalContrast</code>, <code>blindContrast</code>, <code>redContrast</code>, <code>greenContrast</code></td></tr>
    <tr><td><code>A</code>, <code>A+</code>, <code>A-</code></td><td><code>baseTextSize</code>, <code>lgTextSize</code>, <code>smTextSize</code></td></tr>
    <tr><td>Listen</td><td>Opens <code>read-speaker-link</code></td></tr>
  </tbody>
</table>

The Screen Reader item shows only when `read-speaker-link` is set.

## Links and labels

- **Logo links.** `first-logo-href` and `second-logo-href` set the link of each logo. Both default
  to `/`, the root of the domain. If your site is served under a subpath (for example
  `https://example.gov.ae/services/`), set them to your home page, such as `/services/` or `./`.
- **Menu button.** `menu_button_label` is the accessible name of the hamburger button. Default:
  `Menu`.
- **Language buttons.** `language_text` is the label of both language buttons (default `العربية`).
  `language_lang` sets their `lang` attribute (default `ar`), so screen readers read the label in
  that language. When the label is English, set `language_lang="en"`.
- **Login link.** `login-text` and `login-icon` set the label and the Material Symbols icon of the
  Login link in the desktop toolbar and the side menu (defaults `Login` and
  `sentiment_satisfied`). `login-link` sets its URL. To remove the link from both places, set
  `hide_login`. An empty `login-text` does not hide the link; it shows the default label.

## Search

The header search is a `<form role="search">`. Enter submits it on desktop. On small screens the
search button opens a search field under the header; Escape or the close button dismisses it.
Empty searches do nothing.

Every non-empty search emits a cancelable `searchSubmit` event with `detail.query`. What
happens next depends on two things:

<table>
  <thead><tr><th><code>search_action</code> set</th><th>Event cancelled</th><th>Result</th></tr></thead>
  <tbody>
    <tr><td>yes</td><td>no</td><td>The browser goes to <code>search_action?q=&lt;query&gt;</code> (a plain GET, no JavaScript needed).</td></tr>
    <tr><td>yes</td><td>yes</td><td>No navigation; your code handles the search.</td></tr>
    <tr><td>no</td><td>either</td><td>No navigation; your code handles the search.</td></tr>
  </tbody>
</table>

The query parameter is named by `search_input_name` and defaults to `q`.

#### Static site: send searches to a results page

```html
<dda-header search_action="/search.html" search_input_name="q"></dda-header>
```

`/search.html` reads the query with `new URLSearchParams(location.search).get('q')`.

#### Framework app: route the search yourself

```jsx
// React
<DdaHeader
  search_action="/search"
  onSearchSubmit={event => {
    event.preventDefault();
    navigate(`/search?q=${encodeURIComponent(event.detail.query)}`);
  }}
/>
```

Keeping `search_action` set means the search still works if JavaScript has not loaded yet.
