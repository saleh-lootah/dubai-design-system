# Textarea

The `dda-textarea` component renders a labelled multi-line `<textarea>` with helper text, an error
message and a character count. Set `enable_rich_editor` to use a Quill rich text editor instead.

## API

<Markdown>{componentApi(readme)}</Markdown>

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-textarea
  input_id="request-details"
  textarea_name="request_details"
  label="Request details"
  placeholder="Describe your request"
  helper_text="Include your application number if you have one."
  max_characters="500"
></dda-textarea>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-textarea.js';

const textarea = document.querySelector('dda-textarea');
textarea.addEventListener('input', event => {
  // The native input event comes from the inner <textarea>. The value prop also updates.
  console.log(event.target.value, textarea.value);
});
```

## Character count

`max_characters` sets the `maxlength` of the textarea. The count (for example `120 / 500`) shows next
to `helper_text` or `error_message`, so set one of them to show the count.

## Validation and error messages

The component does not validate input. Validate the value in your application, then set
`validation_type="error"` for the error colors and `error_message` for the message.

```html
<dda-textarea
  input_id="request-details"
  textarea_name="request_details"
  label="Request details"
  max_characters="500"
  validation_type="error"
  error_message="Enter the details of your request."
></dda-textarea>
```

## Rich text editor

Set `enable_rich_editor` to replace the textarea with a Quill editor and toolbar. The `value` prop
then holds the editor content as HTML. Read it from the element:

```js
const editor = document.querySelector('dda-textarea[enable_rich_editor]');
const html = editor.value;
```

In rich text mode `max_characters` does not limit the input, and `textarea_name` and `aria_label` are
not used. The editor is not a form field, so copy `value` into your form data yourself.

## Accessibility

- Always set `input_id`. The label and the ids of the helper and error text come from it.
- `helper_text` and `error_message` are linked to the field with `aria-describedby`.
  When `error_message` is set, the field also gets `aria-invalid="true"`.
- In rich text mode the editable area gets `role="textbox"`, `aria-multiline="true"` and is labelled
  by the visible `label`.
- Use `aria_label` only when the field has no visible `label`.
- `input_status="disabled"` changes only the styling. The field still receives focus and input.
