# UI Card

The `dda-ui-card` component renders a content card with an optional icon or image, a title, a
subtitle and a link. Content between the tags goes into a slot after these parts. Set
`type="custom"` to render only the slot content inside the card frame. When the user clicks the
link, the component fires `linkClick` with the original click `MouseEvent` as `detail`.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-ui-card
  icon="description"
  maintitle="Trade licence renewal"
  subtitle="Renew your trade licence online in a few steps."
  link="/services/trade-licence-renewal"
  linktext="Start service"
></dda-ui-card>

<script>
  document
    .querySelector('dda-ui-card')
    .addEventListener('linkClick', () => console.log('Start service clicked'));
</script>

<dda-ui-card type="custom">
  <h2 class="dda-card-title">Need help?</h2>
  <p class="dda-card-text-muted">Call the service centre from 8 am to 8 pm.</p>
</dda-ui-card>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-ui-card.js';

const card = document.querySelector('dda-ui-card');
card.subtitle = 'Renew your trade licence online in a few steps.';

// `detail` is the original click. Call preventDefault() on it to route inside a single-page app.
card.addEventListener('linkClick', event => {
  event.detail.preventDefault();
  router.push(card.link);
});
```

### React

```jsx
import { DdaUiCard } from '@dubai-design-system/components-react';

export function RenewalCard() {
  return (
    <DdaUiCard
      icon="description"
      maintitle="Trade licence renewal"
      subtitle="Renew your trade licence online in a few steps."
      link="/services/trade-licence-renewal"
      linktext="Start service"
      onLinkClick={() => console.log('Start service clicked')}
    />
  );
}
```

```html
<dda-ui-card
  icon="description"
  maintitle="Trade licence renewal"
  subtitle="Renew your trade licence online in a few steps."
  link="/services/trade-licence-renewal"
  linktext="Start service"
  (linkClick)="onStartService($event.detail)"

```

## Notes

- `icon` and `linkicon` take Material Icons names. Load the Material Icons font.
- When you set `image`, the component uses `maintitle` as the image alt text.
- The title renders as an `<h3>` by default. Set `heading_level` (1–6) to fit the page outline,
  for example `heading_level="2"` for cards directly under the page `<h1>`. The title looks the
  same at every level.
- The icon and the link arrow are hidden from screen readers, so the link is read as its
  `linktext` only.
- The `linkClick` event fires when the user clicks the link. The browser still follows `link`
  unless a listener calls `event.detail.preventDefault()`.
