# Attach File

The `dda-attach-file` component renders a labelled file picker with a "Choose File" button.
After the user chooses a file, it shows the file name with a file type icon and a button to
remove the file. It accepts one file.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-attach-file
  input_id="trade-licence"
  input_name="trade_licence"
  label="Trade licence"
  helper_text="Upload a PDF of your trade licence."
  button_aria_label="Remove file"
></dda-attach-file>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-attach-file.js';

const attach = document.querySelector('dda-attach-file');

// The component has no custom events. The native `input` event of the inner
// file input bubbles to the host.
attach.addEventListener('input', event => {
  const file = event.target.files?.[0];
  if (file) console.log(file.name, file.size);
});
```

### React

```jsx
import { DdaAttachFile } from '@dubai-design-system/components-react';

export function TradeLicenceUpload({ onFile }) {
  return (
    <DdaAttachFile
      input_id="trade-licence"
      input_name="trade_licence"
      label="Trade licence"
      helper_text="Upload a PDF of your trade licence."
      button_aria_label="Remove file"
      onInput={e => onFile(e.target.files?.[0])}
    />
  );
}
```

## States

- **Error:** set `validation_type="error"` and `error_message`. The file input gets `aria-invalid="true"`.
- **Disabled look:** set `input_type="disabled"`. This changes only the look; the file input stays usable.
- **Small:** set `size="small"`.

## Notes

- The file input stays on the page after a file is chosen, so a native form submit includes the
  file (set `input_name`). The remove button clears the file input. You can also keep the file
  from the `input` event.
- The file icon matches the file extension: `pdf`, `pptx`, `docx`, `xlsx`, `png`, `jpg`,
  `jpeg`, `mp4`, `mkv` and `one`.
- `input_id` is optional. The label, helper text and error message are linked to the file input
  through it. Without `input_id` the component generates a unique id, so these links still work.
  Set `input_id` when your own code or CSS needs a known id.
- The file input is visually hidden but stays in the tab order. When it has keyboard focus, the
  "Choose File" control shows a focus ring. Press Space or Enter to open the file picker.
- Set `button_aria_label` so the icon-only remove button has an accessible name.
