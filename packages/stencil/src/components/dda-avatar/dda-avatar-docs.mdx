# Avatar

The `dda-avatar` component shows a user as a photo, an icon or initials, in six sizes and two shapes.
It can show a status, verified or notification badge. When you set `options`, the avatar becomes a
button that opens a dropdown list. When the user picks an option, the avatar updates its `selected`
property and fires `optionSelect` with `detail.value`, the option.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-avatar type="photo" src="/images/avatar.jpg" size="md" rounded="circle" design="verified"></dda-avatar>

<dda-avatar type="text" text="FA" size="lg" design="notification" notification_number="3"></dda-avatar>

<dda-avatar
  type="photo"
  src="/images/avatar.jpg"
  aria_label="Account menu"
  options='["My profile","My applications","Sign out"]'
></dda-avatar>

<script>
  document
    .querySelector('dda-avatar[options]')
    .addEventListener('optionSelect', event => console.log('Account menu:', event.detail.value));
</script>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-avatar.js';

const avatar = document.querySelector('dda-avatar');
avatar.options = JSON.stringify(['My profile', 'My applications', 'Sign out']);
avatar.addEventListener('optionSelect', event => {
  if (event.detail.value === 'Sign out') signOut();
});
```

### React

```jsx
import { DdaAvatar } from '@dubai-design-system/components-react';

export function AccountAvatar({ onMenuSelect }) {
  return (
    <DdaAvatar
      type="photo"
      src="/images/avatar.jpg"
      size="md"
      aria_label="Account menu"
      options={JSON.stringify(['My profile', 'My applications', 'Sign out'])}
      onOptionSelect={event => onMenuSelect(event.detail.value)}
    />
  );
}
```

### Vue

```html
<script setup>
import { DdaAvatar } from '@dubai-design-system/components-vue';

const options = JSON.stringify(['My profile', 'My applications', 'Sign out']);
</script>

<template>
  <DdaAvatar
    type="photo"
    src="/images/avatar.jpg"
    size="md"
    aria_label="Account menu"
    :options="options"
    @optionSelect="event => console.log('Account menu:', event.detail.value)"
  />
</template>
```

### Angular

```html

  size="md"
```
