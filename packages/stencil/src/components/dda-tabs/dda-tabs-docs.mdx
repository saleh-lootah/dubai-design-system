# Tabs

The `dda-tabs` component renders a row of tab buttons from a JSON list of labels. One tab is
active at a time (the first on load). The component renders no panels: listen for `tabClick`
and show your own content for the selected index. `detail` is the index of the clicked tab, a
number from 0.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-tabs
  type="text-icon"
  hover_style="dda-tab-underline"
  aria_label="Application sections"
  tab_texts='["Details", "Documents", "Payment"]'
  tab_icons='["person", "folder", "payments"]'
></dda-tabs>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-tabs.js';

const tabs = document.querySelector('dda-tabs');
tabs.tab_texts = JSON.stringify(['Details', 'Documents', 'Payment']);
tabs.addEventListener('tabClick', e => console.log('selected tab', e.detail));
```

### React

```jsx
import { DdaTabs } from '@dubai-design-system/components-react';

export function ApplicationTabs() {
  return (
    <DdaTabs
      hover_style="dda-tab-underline"
      aria_label="Application sections"
      tab_texts={JSON.stringify(['Details', 'Documents', 'Payment'])}
      onTabClick={e => console.log('selected tab', e.detail)}
    />
  );
}
```

### Vue

```html
<script setup>
import { DdaTabs } from '@dubai-design-system/components-vue';

const tabTexts = JSON.stringify(['Details', 'Documents', 'Payment']);
</script>

<template>
  <DdaTabs
    hover_style="dda-tab-underline"
    aria_label="Application sections"
    :tab_texts="tabTexts"
    @tabClick="e => console.log('selected tab', e.detail)"
  />
</template>
```

### Angular

```html
<dda-tabs
  hover_style="dda-tab-underline"
  aria_label="Application sections"
  tab_texts='["Details", "Documents", "Payment"]'
  (tabClick)="onTabClick($event.detail)"
></dda-tabs>
```

## Accessibility

The component has no panels, so it does not use `role="tablist"` or `role="tab"`. It is a group of
toggle buttons: `role="group"` on the container and `aria-pressed` on each button. Set
`aria_label` to give the group an accessible name.
