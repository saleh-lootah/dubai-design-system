# Radio Button

The `dda-radiobutton` component renders a native radio input with a styled circle, a title and
optional supporting text. Give the radio buttons of one question the same `group_name` so the user
can select only one.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<div id="delivery">
  <dda-radiobutton
    input_id="delivery-email"
    group_name="delivery"
    title_text="Email"
    supporting="Receive the certificate by email"
    size="md"
    checked
  ></dda-radiobutton>
  <dda-radiobutton
    input_id="delivery-courier"
    group_name="delivery"
    title_text="Courier"
    supporting="Receive a printed certificate at your address"
    size="md"
  ></dda-radiobutton>
</div>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-radiobutton.js';

// The component has no custom events. The native `change` event of the inner input bubbles up.
document.querySelector('#delivery').addEventListener('change', event => {
  console.log('Delivery:', event.target.id);
});
```

### React

```jsx
import { DdaRadiobutton } from '@dubai-design-system/components-react';

export function DeliveryMethod() {
  const onChange = event => console.log('Delivery:', event.target.id);

  return (
    <>
      <DdaRadiobutton input_id="delivery-email" group_name="delivery" title_text="Email" supporting="Receive the certificate by email" size="md" checked onChange={onChange} />
      <DdaRadiobutton input_id="delivery-courier" group_name="delivery" title_text="Courier" supporting="Receive a printed certificate at your address" size="md" onChange={onChange} />
    </>
  );
}
```

### Vue

```html

const onChange = event => console.log('Delivery:', event.target.id);

</template>
```

```html
<dda-radiobutton input_id="delivery-email" group_name="delivery" title_text="Email" supporting="Receive the certificate by email" size="md" [checked]="true" (change)="onDeliveryChange($event)"></dda-radiobutton>
<dda-radiobutton input_id="delivery-courier" group_name="delivery" title_text="Courier" supporting="Receive a printed certificate at your address" size="md" (change)="onDeliveryChange($event)"></dda-radiobutton>
```

## Groups and ids

- Radio buttons with the same `group_name` share the `name` of their inner inputs, so selecting one
  clears the others.
- Set a unique `input_id` on every radio button. The label points to the input by this id, so
  without it clicking the title does not select the radio button.
- The inner input has no `value` attribute. Use the input `id` to know which option is selected.
