# Button

The `dda-button` component renders a native `<button>` with Dubai Design System colors, sizes
and optional Material Symbols icons. Put the label between the tags.

## API

<Markdown>{componentApi(readme)}</Markdown>

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-button button_id="save" button_color="default-primary" end_icon="arrow_forward">
  Save and continue
</dda-button>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-button.js';

const button = document.querySelector('dda-button');
button.addEventListener('click', () => console.log('clicked'));
```

### React

```jsx
import { DdaButton } from '@dubai-design-system/components-react';

export function SaveButton() {
  return (
    <DdaButton button_id="save" button_color="default-primary" end_icon="arrow_forward" onClick={() => console.log('clicked')}>
      Save and continue
    </DdaButton>
  );
}
```

### Vue

```html
<script setup>
import { DdaButton } from '@dubai-design-system/components-vue';
</script>

<template>
  <DdaButton button_id="save" button_color="default-primary" end_icon="arrow_forward" @click="console.log('clicked')">
    Save and continue
  </DdaButton>
</template>
```

### Angular

```html
<dda-button button_id="save" button_color="default-primary" end_icon="arrow_forward" (click)="save()">
  Save and continue
</dda-button>
```
