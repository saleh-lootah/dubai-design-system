# Link Button

The `dda-link-button` component renders a native `<a>` link that looks like a `dda-button`. It uses the
same colors, sizes, shapes and Material Symbols icons. Use it for navigation; use `dda-button` for
actions. Put the label between the tags.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-link-button button_id="apply-link" href="/services/apply" button_color="default-primary" end_icon="arrow_forward">
  Apply for a permit
</dda-link-button>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-link-button.js';

const link = document.querySelector('dda-link-button');
link.href = '/services/apply';
```

### React

```jsx
import { DdaLinkButton } from '@dubai-design-system/components-react';

export function ApplyLink() {
  return (
    <DdaLinkButton button_id="apply-link" href="/services/apply" button_color="default-primary" end_icon="arrow_forward">
      Apply for a permit
    </DdaLinkButton>
  );
}
```

## Icon-only links

When the link shows only an icon, set `aria_label` so screen readers can announce it.

```html
<dda-link-button href="/help" button_color="default-tertiary" icon_button_shape="circle" start_icon="help" aria_label="Help"></dda-link-button>
```
