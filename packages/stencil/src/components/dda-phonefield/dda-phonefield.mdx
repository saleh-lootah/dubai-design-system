# Phone Field

The `dda-phonefield` component renders a phone number input with a country code dropdown. The
country code starts as `+971` (United Arab Emirates). The number input is a native `type="number"` input.

## API

<Markdown>{componentApi(readme)}</Markdown>

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-phonefield
  input_id="mobile-number"
  phone_input_name="mobile_number"
  label="Mobile number"
  placeholder="501234567"
  helper_text="We send a verification code to this number."
></dda-phonefield>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-phonefield.js';

const phone = document.querySelector('dda-phonefield');

// The native input event comes from the inner <input>.
phone.addEventListener('input', event => console.log(event.target.value));
```

```jsx

```

### Vue

```html
<script setup>
import { DdaPhonefield } from '@dubai-design-system/components-vue';

}
</script>

<template>

    label="Mobile number"
    placeholder="501234567"

```

### Angular

```html
<dda-phonefield
  input_id="mobile-number"
  phone_input_name="mobile_number"
  label="Mobile number"

  helper_text="We send a verification code to this number."

></dda-phonefield>
```


## Behaviour

- The phone input is a native `type="number"` input. The component removes every character that is
  not a digit or `.` from its value.
- The selected country code is internal state. It is not a prop, it fires no event and it is not
  submitted with the form. Only the phone number (`phone_input_name`) is submitted.
- The component has no `value` prop. Read the number from the inner `<input>`.

## Validation and error messages

The component does not validate the number. Validate it in your application, then set
`validation_type="error"` for the error colors and `error_message` for the message.
When `validation_type` has any value, `helper_text` is hidden.

```html
<dda-phonefield
  input_id="mobile-number"
  phone_input_name="mobile_number"
  label="Mobile number"
  validation_type="error"
  error_message="Enter a mobile number with 9 digits."
></dda-phonefield>
```

## Disabled

Set `disabled` to disable the phone input. The country code button is not disabled.

```html
<dda-phonefield input_id="mobile-number" label="Mobile number" disabled></dda-phonefield>
```

## Accessibility

- Always set `input_id`. The label `for`, and the ids of the helper and error text, come from it.
- `autocomplete` defaults to `tel`, so browsers can fill in the number.
- `helper_text` and `error_message` are linked to the input with `aria-describedby`.
  When `error_message` is set, the input also gets `aria-invalid="true"`.
- Use `aria_label` only when the field has no visible `label`.
