# Sticky Footer

The `dda-sticky-footer` component renders a bar fixed to the bottom of the page with three groups of
icon links: happiness, accessibility and services on the left; up to three logos in the middle;
location, news, AI assistant and chat on the right. Each icon is an image link with a tooltip. The
bar hides while the user scrolls down and shows again when they scroll up.

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-sticky-footer.js';

const bar = document.querySelector('dda-sticky-footer');
bar.hideMiddleSection = true;
```

## Behaviour

- **Middle section.** The logos show only when `hide-middle-section` is set to `false`. If you do
  not set it, the middle section is hidden.
- **Every icon renders.** The component always renders all icon slots. Set the `src`, `alt` and
  tooltip of each icon you use; an icon without a `src` shows as an empty link.
- **Hide on scroll.** While the page scrolls down the bar hides and becomes `inert`; scrolling up
  shows it again.
- **Page layout.** The component sets the CSS variable `--dda-sticky-footer-height` on `<html>` to
  the bar's height, so content fixed above the bar can clear it.
