# Sticky Footer

The `dda-sticky-footer` component renders a bar fixed to the bottom of the page with three groups of
icon links: happiness, accessibility and services on the left; up to three logos in the middle;
location, news, AI assistant and chat on the right. Each icon is an image link with a tooltip
(location and news can use a Material Symbols icon instead). The
bar hides while the user scrolls down and shows again when they scroll up.

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';

const bar = document.querySelector('dda-sticky-footer');

```

## Behaviour

- **Middle section.** The logos show when at least one of `first-logo-src`, `second-logo-src` or
  `third-logo-src` is set. Set `hide-middle-section` to hide them anyway.
- **Items render only when set.** Each icon renders only when its image (or, for services, its
  text) is set. An icon with no image and no text does not render.
- **Dark images.** Set `color-theme="dark"` to use each `*-icon-src-dark` image instead of its
  `*-icon-src` image. An icon with no dark image keeps its light image.
- **Links to open a script's popup.** Set `happiness-icon-id`, `accessibility-icon-id`,
  `services-icon-id`, `ai-icon-id` or `chat-icon-id` to give a link a fixed `id`, for a page script
  that opens a popup from that link.
- **Hide on scroll.** While the page scrolls down the bar hides and becomes `inert`; scrolling up
  shows it again.
- **Page layout.** The component sets the CSS variable `--dda-sticky-footer-height` on `<html>` to
  the bar's height, so content fixed above the bar can clear it.
- **Landmark.** The bar is an `<aside>` landmark, not a second `<footer>`. `aria_label` names it;
  default: `Quick actions`.
- **Services text.** When `services-icon-text` is set, the text names the link and the icon image
  gets `alt=""`. Set `services-icon-alt` for an icon without text.
- **Location and news icons.** Each link shows an image (`location-logo-src`,
  `news-button-src`) or a Material Symbols icon (`location-button-icon`, `news-button-icon`). The
  image wins when both are set. With an icon, `location-button-text` and `news-button-text` name
  the link as visually hidden text and remain the tooltip text.
