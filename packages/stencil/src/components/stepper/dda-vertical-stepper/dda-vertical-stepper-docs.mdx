# Vertical Stepper

The `dda-vertical-stepper` component shows the steps of a process in a column, each with an icon,
title, subtitle and description. `current_step` is an index from 0: that step and all steps before
it show as active. The stepper is display only; it has no events.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-vertical-stepper
  current_step="1"
  steps='[{"icon":"person","title":"Step 1","subtitle":"Applicant details","description":"Enter your name and Emirates ID."},{"icon":"folder","title":"Step 2","subtitle":"Documents","description":"Upload the required documents."},{"icon":"payments","title":"Step 3","subtitle":"Payment","description":"Pay the service fee."}]'
></dda-vertical-stepper>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-vertical-stepper.js';

const stepper = document.createElement('dda-vertical-stepper');
stepper.steps = JSON.stringify([
  { icon: 'person', title: 'Step 1', subtitle: 'Applicant details', description: 'Enter your name and Emirates ID.' },
  { icon: 'folder', title: 'Step 2', subtitle: 'Documents', description: 'Upload the required documents.' },
  { icon: 'payments', title: 'Step 3', subtitle: 'Payment', description: 'Pay the service fee.' },
]);
stepper.current_step = 1;
document.body.append(stepper);
```

You can change `steps` and `current_step` at any time. A missing or invalid `steps` value renders no steps.

### React

```jsx
import { DdaVerticalStepper } from '@dubai-design-system/components-react';

const steps = [
  { icon: 'person', title: 'Step 1', subtitle: 'Applicant details', description: 'Enter your name and Emirates ID.' },
  { icon: 'folder', title: 'Step 2', subtitle: 'Documents', description: 'Upload the required documents.' },
  { icon: 'payments', title: 'Step 3', subtitle: 'Payment', description: 'Pay the service fee.' },
];

export function ApplicationProgress({ step }) {
  return <DdaVerticalStepper steps={JSON.stringify(steps)} current_step={step} />;
}
```

## The current step

Use `current_step` (attribute `current_step`). The older `current_Step` property is deprecated:
its attribute name is `current_-step`, so it never worked in HTML. When both are set,
`current_step` wins.
