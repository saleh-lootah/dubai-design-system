# Progress Bar

The `dda-progressbar` component shows how far a task has progressed, as a bar filled from 0 to
100 percent. It can also show the percentage in a tooltip or as text after the bar.

## API

<Markdown>{componentApi(readme)}</Markdown>

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-progressbar progress="40" show_percentage_text aria_label="Application progress"></dda-progressbar>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-progressbar.js';

const bar = document.querySelector('dda-progressbar');
bar.progress = 60;
```

### React

```jsx
import { DdaProgressbar } from '@dubai-design-system/components-react';

export function ApplicationProgress({ percent }) {
  return <DdaProgressbar progress={percent} tooltip tooltip_position="top" aria_label="Application progress" />;
}
```

### Vue

```html
<script setup>
import { DdaProgressbar } from '@dubai-design-system/components-vue';

defineProps({ percent: Number });
</script>

<template>
  <DdaProgressbar :progress="percent" :tooltip="true" tooltip_position="top" aria_label="Application progress" />
</template>
```

### Angular

```html
<dda-progressbar [progress]="percent" [tooltip]="true" tooltip_position="top" aria_label="Application progress"></dda-progressbar>
```

## Notes

- `progress` is a percentage. The component does not clamp it, so pass a value from 0 to 100.
- The element has `role="progressbar"` with `aria-valuemin="0"`, `aria-valuemax="100"` and
  `aria-valuenow` set from `progress`. Set `aria_label` to describe the task; the default is "Progress".
- When you use `tooltip`, leave space above (`top`) or below (`bottom`) the bar for it.
