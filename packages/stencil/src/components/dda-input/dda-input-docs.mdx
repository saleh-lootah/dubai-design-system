# Input

The `dda-input` component renders a labelled native `<input>` with optional helper text and an
error message. Set `type` for text, email, password, number, date or time input.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-input
  input_id="full-name"
  input_name="full_name"
  label="Full name"
  placeholder="As shown on your Emirates ID"
  helper_text="Enter your name in English."
></dda-input>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-input.js';

const input = document.querySelector('dda-input');
input.addEventListener('input', event => {
  // The native input event comes from the inner <input>. The value prop also updates.
  console.log(event.target.value, input.value);
});
```

### React

```jsx
import { DdaInput } from '@dubai-design-system/components-react';

export function FullNameField() {
  return (
    <DdaInput
      input_id="full-name"
      input_name="full_name"
      label="Full name"
      placeholder="As shown on your Emirates ID"
      helper_text="Enter your name in English."
      onInput={event => console.log(event.target.value)}
    />
  );
}
```

### Vue

```html
<script setup>
import { DdaInput } from '@dubai-design-system/components-vue';

function onInput(event) {
  console.log(event.target.value);
}
</script>

<template>
  <DdaInput
    input_id="full-name"
    input_name="full_name"
    label="Full name"
    placeholder="As shown on your Emirates ID"
    helper_text="Enter your name in English."
    @input="onInput"
  />
</template>
```

### Angular

```html
<dda-input
  input_id="full-name"
  input_name="full_name"
  label="Full name"
  placeholder="As shown on your Emirates ID"
  helper_text="Enter your name in English."
  (input)="onInput($event)"
></dda-input>
```


## Validation and error messages

The component does not validate input. Validate the value in your application, then set
`validation_type="error"` for the error colors and `error_message` for the message.

```html
<dda-input
  input_id="email"
  input_name="email"
  type="email"
  label="Email address"
  value="name@example"
  validation_type="error"
  error_message="Enter an email address in the format name@example.com."
></dda-input>
```

Clear both props when the value is valid again.

## Accessibility

- Always set `input_id`. The label `for`, and the ids of the helper and error text, come from it.
  Without `input_id` the label is not linked to the input.
- `helper_text` and `error_message` are linked to the input with `aria-describedby`.
  When `error_message` is set, the input also gets `aria-invalid="true"`.
- Use `aria_label` only when the field has no visible `label`.
- `input_status="disabled"` changes only the styling. The input still receives focus and input.
