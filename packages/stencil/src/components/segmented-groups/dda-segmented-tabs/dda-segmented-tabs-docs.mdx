# Segmented Tabs

The `dda-segmented-tabs` component is a group of mutually exclusive toggle buttons. Exactly one
segment is selected at a time: the first by default, or the one named by `selected_index`.
Selecting a different segment fires `segmentChange` with the new index.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-segmented-tabs
  radius_type="rounded"
  aria_label="Filter applications"
  items='["All", "Pending", "Approved"]'
  selected_index="0"
></dda-segmented-tabs>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-segmented-tabs.js';

const segments = document.querySelector('dda-segmented-tabs');
segments.addEventListener('segmentChange', e => console.log('selected segment', e.detail));
```

You can change `items` and `selected_index` at any time. A missing or invalid `items` value renders no segments.

### React

```jsx
import { DdaSegmentedTabs } from '@dubai-design-system/components-react';

export function ApplicationFilter() {
  return (
    <DdaSegmentedTabs
      radius_type="rounded"
      aria_label="Filter applications"
      items={JSON.stringify(['All', 'Pending', 'Approved'])}
      selected_index={0}
      onSegmentChange={e => console.log('selected segment', e.detail)}
    />
  );
}
```

### Vue

```html
<script setup>
import { DdaSegmentedTabs } from '@dubai-design-system/components-vue';

const items = JSON.stringify(['All', 'Pending', 'Approved']);

  />
</template>
```

## Icon segments

An item that starts with `fo` renders as a Material Symbols icon instead of text, for example
`'["format_align_left", "format_align_center", "format_align_right"]'`. Icon segments have no
visible label, so give the group a clear `aria_label`, and give each icon segment an accessible
name with `icon_labels`: a JSON string array in the same order as `items`, for example
`icon_labels='["Align left", "Align center", "Align right"]'`. Without it, the segment name is the
icon name with spaces, such as "format align left".

## Accessibility

The component uses `role="group"` with `aria-pressed` on each button. It is not the WAI tabs
pattern: it has no associated panels, so it does not use `role="tablist"`, `role="tab"` or
`aria-selected`. Pass `aria_label` to give the group an accessible name. Users select a segment
with a click, or with Tab and then Enter or Space.
