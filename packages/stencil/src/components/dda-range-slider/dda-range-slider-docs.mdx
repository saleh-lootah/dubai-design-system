# Range Slider

The `dda-range-slider` component renders two native range inputs on one track, so the user can
select a lower and an upper value. The selected part of the track is filled, and each handle
value shows in a label or tooltip.

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-range-slider
  min="0"
  max="100"
  step="5"
  initial_min="20"
  initial_max="80"
  tooltip_position="top"
  left_input_id="completion-min"
  right_input_id="completion-max"
  left_aria_label="Minimum completion"
  right_aria_label="Maximum completion"
  left_input_name="completion_min"
  right_input_name="completion_max"
></dda-range-slider>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-range-slider.js';

const slider = document.querySelector('dda-range-slider');

// The component has no custom events. The native `input` event of each inner
// range input bubbles to the host; read both values from the inputs.
slider.addEventListener('input', () => {
  const [lower, upper] = slider.querySelectorAll('input[type="range"]');
  console.log(Number(lower.value), Number(upper.value));
});
```

## Notes

- `initial_min` and `initial_max` set the start positions only. Changing them after the
  component loads does not move the handles.
- The value labels always end with `%`, so the slider suits percentage ranges best.
- Set `left_aria_label` and `right_aria_label` so screen reader users can tell the two handles apart.
