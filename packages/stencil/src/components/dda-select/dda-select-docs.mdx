# Select

The `dda-select` component renders a labelled trigger button that opens a list of options. Pass
the options as a JSON array string and read the chosen value from the `selected` property.

## API

<Markdown>{componentApi(readme)}</Markdown>

## Usage

### Vanilla JS

**From the CDN.** Replace `X.X.X` with the exact package version.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/dist/dda/dda.css" />
<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons" />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />
<script type="module">
  import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@dubai-design-system/components-js@X.X.X/loader/index.es2017.js';
  defineCustomElements();
</script>

<dda-select
  button_id="emirate"
  label="Emirate"
  helper_text="Select the emirate of your residence"
  options='["Dubai","Abu Dhabi","Sharjah"]'
></dda-select>
```

**From npm with a bundler (Vite, Rollup).** Import the component file; it defines the element.

```js
import '@dubai-design-system/components-js/dist/dda/dda.css';
import '@dubai-design-system/components-js/dist/components/dda-select.js';

const select = document.querySelector('dda-select');
select.options = JSON.stringify(['Dubai', 'Abu Dhabi', 'Sharjah']);

// The component does not emit a change event. Read the `selected` property when you need the value.
document.querySelector('#continue').addEventListener('click', () => {
  console.log('Emirate:', select.selected);
});
```

### React

```jsx
import { useRef } from 'react';
import { DdaSelect } from '@dubai-design-system/components-react';

export function EmirateSelect() {
  const select = useRef(null);

  return (
    <>
      <DdaSelect
        ref={select}
        button_id="emirate"
        label="Emirate"
        helper_text="Select the emirate of your residence"
        options={JSON.stringify(['Dubai', 'Abu Dhabi', 'Sharjah'])}
      />
      <button type="button" onClick={() => console.log('Emirate:', select.current.selected)}>Continue</button>
    </>
  );
}
```

### Vue

## Errors

Set `error="error"` to show the error styling and `error_message` to show the message. The message
is linked to the trigger with `aria-describedby`, and the trigger gets `aria-invalid="true"`.

```html
<dda-select
  button_id="emirate"
  label="Emirate"
  options='["Dubai","Abu Dhabi","Sharjah"]'
  error="error"
  error_message="Select an emirate"
></dda-select>
```

## Keyboard

- **Arrow Down / Arrow Up** on the trigger opens the list and moves focus to the selected option.
- **Arrow Down / Arrow Up, Home, End** move between options.
- **Enter / Space** selects the focused option and returns focus to the trigger.
- **Escape** closes the list. **Tab** closes the list and moves focus on.

Set a unique `button_id`. The component uses it for the list, helper text and error message ids.
